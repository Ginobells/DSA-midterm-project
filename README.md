Clinic Patient Queue System

 Project Overview
The Clinic Patient Queue System is a Java-based desktop application designed to help clinics manage patient registration and waiting queues efficiently. The system organizes patients based on their registration order and allows clinic staff to register, view, search, and call patients.

Objectives
- To organize patients in a first-come, first-served order.
- To simplify patient registration and queue management.
- To provide an efficient way to search for patient information.
- To reduce confusion in managing the clinic's waiting list.

 Features
- Patient Registration – Register patients by entering their ID, name, age, and reason for consultation.
- View Waiting List – Display patients currently waiting for consultation.
- Call Next Patient – Call the next patient in the queue.
- Search Patient – Find patient information using their Patient ID.

Technologies Used
- Java
- NetBeans IDE
- GitHub

Data Structure
The system uses a manually implemented Queue using an array.

The Queue follows the First-In, First-Out (FIFO) principle, meaning the patient who registers first will be called first.

Patient searching is implemented using manual linear searching.

How to Run
1. Clone or download this repository.
2. Open NetBeans IDE.
3. Select File → Open Project.
4. Open the downloaded project.
5. Run the main JFrame class.
